Neste exercício construiremos um diagrama de classes utilizando o PlantUML.

## Diagrama

Desenhe aqui o seu diagrama.

```plantuml
@startuml
hide circle
left to right direction

'skinparam classAttributeIconSize 0
'skinparam classFontStyle bold
'skinparam classFontSize 14
'skinparam classBackgroundColor LightBlue
'skinparam classStereotypeFontSize 12


class Pessoa {
  -email: String
  -nome: String
  -cpf: String
}

class ComponenteCurricular {
  -id: String
  -nome: String
  -cargaHoraria: Integer
}

class Turma {
  -id: String
  -vagas: String
}

class Professor {
  -matricula: String
}

class Aluno {
  -ra: String
  -dataDeIngresso: date
}

class Aula {
    -id: String
    -sala: String
    -horario: String
    -data: date
}

Pessoa <|-- Aluno
Pessoa <|-- Professor
Turma "1..*" o-- "1" Professor : leciona
Turma "1..*" o-- "1..*" Aluno : matricula
Turma "1" *-- "1..*" Aula : compõe
ComponenteCurricular "1" *-- "1..*" Turma : compõe

@enduml
